# ระบบจัดการบันทึกส่วนบุคคล (Python + Flask)

## วิธีเปิดใช้งานบน Windows

1. ติดตั้ง Python 3 จาก https://www.python.org/downloads/
   ระหว่างติดตั้งให้เลือก `Add Python to PATH`
2. แตกไฟล์ ZIP นี้
3. เปิด Command Prompt หรือ Terminal ในโฟลเดอร์ที่แตกไฟล์
4. ติดตั้ง Flask ด้วยคำสั่ง:

   ```bash
   py -m pip install -r requirements.txt
   ```

5. เปิดเว็บแอปด้วยคำสั่ง:

   ```bash
   py app.py
   ```

6. เปิดเบราว์เซอร์และไปที่ `http://127.0.0.1:5000`

กด Ctrl+C ในหน้าต่าง Terminal เพื่อหยุดเซิร์ฟเวอร์

## ความสามารถ
- เพิ่มบันทึก พร้อมชื่อเรื่อง รายละเอียด วันที่ หมวดหมู่ และคำสำคัญ
- ค้นหาด้วยคำสำคัญและกรองหมวดหมู่
- เรียงตามวันที่หรือชื่อเรื่อง
- แก้ไขและลบบันทึก
- สรุปจำนวนบันทึกตามหมวดหมู่
- เก็บข้อมูลไว้ใน `personal_notes.json` อัตโนมัติ

## หมายเหตุ
เว็บนี้ทำงานบนเครื่องของคุณ (localhost) ไม่ได้เผยแพร่สู่สาธารณะโดยอัตโนมัติ
หากต้องการเผยแพร่บนอินเทอร์เน็ต ต้องนำไปติดตั้งบนบริการโฮสติ้งและตั้งค่าความปลอดภัยก่อน
อย่าใช้ข้อมูลส่วนบุคคลที่อ่อนไหวในเวอร์ชันตัวอย่างนี้ เพราะยังไม่มีระบบบัญชีผู้ใช้หรือการเข้ารหัสข้อมูล
